01 Your sequence

Separate keys with spaces or commas. Mix styles with f-up (filled), h-right (hollow), etc.

Supported keys

Movement up / down / left / right · ArrowUp / ArrowDown / ArrowLeft / ArrowRight · W / S / A / D · ↑ / ↓ / ← / →

Arrow styles Add f- (filled) or h- (hollow) to any movement key, e.g. h-up, f-D, h-←. The longer filled- and hollow- prefixes also work. Unprefixed keys use the default style below.
